Calculo para consumo de aparelhos eletricos⚡.

Utilizei a linguagem ![Python](https://img.shields.io/badge/python-%233670A0.svg?style=for-the-badge&logo=python&logoColor=ffdd54)

O objetivo é calcular 🧮 o consumo mensal de qual quer aparelho eletrico atraves da formula "consumoMensal = (potencia * horasDia * 30) / 1000" 
e o gasto  "valor_consumo = consumo_mensal * 0.75".

É necessario as informações de consumo do aparelho, como potencia e o tempo que ele é utilizado.
